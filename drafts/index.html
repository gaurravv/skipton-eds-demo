Skipton EDS + DA coexistence demo

This repository shows one section of an existing AEM site — Help and Support — rebuilt as an Edge Delivery Services page, authored in Document Authoring, sitting alongside the rest of the site on AEM Sites with Core Components.

What's in this demo

Help and Support (EDS + DA)

The Help and Support section, rebuilt block by block and authored in Document Authoring. This is the page to open during the demo.

Rest of the site (AEM Core Components)

In a real coexistence setup, every other section (Savings, Mortgages, Insurance, etc.) stays exactly as it is today on your AEM author/publish instance. See DEMO.md for how the two are wired together via CDN path routing.
